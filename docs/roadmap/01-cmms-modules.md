# CMMS Modules

## Purpose

Defines the functional modules included in **Operix CMMS**.

| Module                   | Description                                           |
| ------------------------ | ----------------------------------------------------- |
| Organization Management  | Manage organizations.                                 |
| User & Access Management | Manage users, roles, permissions, and authentication. |
| Asset Management         | Manage assets throughout their lifecycle.             |
| Asset Categories         | Classify and organize assets.                         |
| Department Management    | Manage organizational departments.                    |
| Location Management      | Manage physical locations.                            |
| Work Order Management    | Manage corrective maintenance work orders.            |
| Preventive Maintenance   | Manage preventive maintenance schedules.              |
| Spare Parts & Inventory  | Manage spare parts, inventory, and stock movements.   |
| Vendor Management        | Manage vendors and suppliers.                         |
| Dashboard & Reporting    | View dashboards, KPIs, and reports.                   |
| Audit & Activity Logs    | Track system activities for auditing.                 |
